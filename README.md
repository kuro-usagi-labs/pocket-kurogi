# Pocket Kurogi: The Vault

A Financial Analyst UI prototype built with React, Lucide-React, and Tailwind CSS.

## Features
- **Intelligent Financial Assistant**: AI-powered chat interface for transaction logging.
- **Portfolio Management**: Multi-wallet tracking (BCA, Gopay, Cash, etc.).
- **Dynamic Analytics**: Real-time spending analysis and category breakdown.
- **Minimalist Design**: Premium Jakarta Plus Sans typography and smooth glassmorphism aesthetics.

## Tech Stack
- React
- Tailwind CSS
- Lucide React
- Gemini AI (Integration Ready)
- Supabase (Backend Ready)
